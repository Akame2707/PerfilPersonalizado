# 🎨 Perfil Personalizado — Formulário Interativo

Um formulário interativo simples e divertido que permite criar um **perfil personalizado** com suas informações, cor favorita e interesses.  
Após preencher o formulário, os dados são salvos no `localStorage` e exibidos em uma página de perfil com animações e personagens chibi da Vocaloid correndo na tela.

---

## ✨ Funcionalidades

- Formulário completo com os campos:
  - Nome
  - Idade
  - Bio
  - Cor favorita (color picker)
  - URL da imagem de perfil
  - Jogo favorito
  - Música favorita
  - Filme favorito
  - Interesse
- Dados salvos no `localStorage`
- Página de perfil dinâmica que carrega as informações preenchidas
- Fundo da página muda de acordo com a cor favorita escolhida
- Animações suaves (foto flutuando, card surgindo, caixas com hover)
- Personagens chibi da Vocaloid (Rin, Len, Meiko, Miku, Luka e Kaito) correndo continuamente na parte inferior da tela
